# v1 scope: add, list, done, remove, a read-only local web view

## Context
The owner's idea: "a command-line to-do list that stores tasks in a JSON file, with add, list, done and remove, plus a one-page web view of the list." For the owner alone, not for sale.

## Options considered
| Option | For | Against |
|---|---|---|
| Read-only page served by `todo serve` on 127.0.0.1 (Q2a, Q3a) | always current; small surface | needs a running command |
| Page that can also change tasks (Q2b) | convenience | doubles the surface; the page could change the file |
| Static HTML file (Q3b) | no server | goes stale |

## Decision
`~/todo.json` (or `TODO_FILE`), stable task numbers never reused, `remove` without a prompt, a read-only page from `todo serve` (SPEC section 1, IR-01 to IR-05). The non-goals are listed in SPEC section 1.

## Consequences
Anything in the non-goals list needs a contract amendment first.

## Revisit when
The owner asks for a non-goal.
