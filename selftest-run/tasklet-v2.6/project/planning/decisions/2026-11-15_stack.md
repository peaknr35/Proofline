# Node 26 with built-in modules only, no dependencies

## Context
Personal tool on one Windows 11 computer. Node v26.4.0 is installed. There is no network, so npm packages cannot be installed (probe, build/INTAKE.md).

## Options considered
| Option | For | Against |
|---|---|---|
| Node 26, built-ins only | runs here now; `node:test`, `node:http` cover tests and the web view | hand-written argument parsing and HTML |
| Node plus npm packages (a CLI parser, a web framework) | less code | no network; more surface to scrub |
| Another language | - | not installed or probed here |

## Decision
Node 26, ES modules, built-in modules only, no dependencies and no lock file (SPEC section 3).

## Consequences
Argument parsing, HTML escaping and the test runner are written by hand and covered by fixtures. Nothing to install.

## Revisit when
A feature is needed that a built-in module cannot provide.
