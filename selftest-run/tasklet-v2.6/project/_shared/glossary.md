# Glossary
<!-- Base: Proofline v2.6 candidate, kit/templates/icm/_shared/glossary.md -->

Exact meanings, taken from `SPEC.md` v0.6. If two parts of the project use one word two ways, fix it here first.

| Word | Means exactly | Not to be confused with |
|---|---|---|
| task | one object in `tasks`: `id`, `title`, `done`, `createdAt`, `doneAt` (SPEC 6.1) | a line of `list` output |
| task number / id | positive integer made from `nextId`, never reused (SPEC 6.1, 6.3) | the task's position in the list |
| task file | the JSON file at `TODO_FILE`, else `<home>/todo.json` (SPEC 5) | the temp file `*.tmp-<pid>-<random>` |
| store | the parsed task file: `version`, `nextId`, `tasks` plus any unknown fields | the file's bytes |
| title | text after `normalizeTitle`: NFC, trimmed, 1-200 code points, no refused characters (SPEC 6.2) | the raw args typed after `add` |
| character (for the 200 limit) | one Unicode code point | a UTF-16 unit, a byte, or what a person sees as one symbol |
| refused character | a match of the regex in SPEC 6.2 (controls, lone surrogates, line/paragraph separators, bidi controls) | any non-ASCII character (those are allowed) |
| done | `done: true` with a `doneAt` timestamp | removed (a removed task is gone) |
| damaged | a task file that fails SPEC 6.1 steps 2-6; never rewritten | missing (missing = empty list) |
| web view / page | the HTML answer to `GET /` from `todo serve` (SPEC 8.2) | any other route (403/404/405) |
| fixture | a file in `contract/fixtures/`, generated by `build/tools/gen-fixtures.mjs` | a test's own sample data |
| unit (U1-U4) | a work unit in SPEC section 4 | a unit test |
