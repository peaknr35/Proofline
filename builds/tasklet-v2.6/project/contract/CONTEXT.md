# contract: golden fixtures

One job: hold the valid and invalid examples that pin every rule in `../SPEC.md`.

## Commands
| Do | Command |
|---|---|
| Regenerate (Lead only, after an approved amendment) | `node build/tools/gen-fixtures.mjs` (from the project root) |
| Check nothing changed since approval | `sha256sum -c build/APPROVED-v0.6.sha256` (from the project root) |

## Inputs
- **Reference (every time):** `../SPEC.md` section 6.4 (which fixture pins which rule)
- **Working (this task):** the one fixture file the question is about
- **Do NOT load:** `fixtures/stores/valid-1000*.json` in full (large, generated); `../src/`

## Process
1. Fixtures are generated by `../build/tools/gen-fixtures.mjs`. Never hand-edit a file in `fixtures/`.
2. A wording or behavior change starts as a contract amendment the owner approves; then the Lead edits the generator and `SPEC.md` together and regenerates.
3. After any change, every unit that loads the changed fixture is stale and is rechecked (`npm test`).

## What is here
- `fixtures/titles.json`, `fixtures/ids.json`: input rules (SPEC 6.2, 6.3)
- `fixtures/stores/` and `fixtures/stores/index.json`: task files and the expected load result (SPEC 6.1)
- `fixtures/help.txt`: exact help text
- `fixtures/cli-cases.json`: command lines, exact output, exit code, end file (its `rule` field explains the placeholders)
- `fixtures/web-cases.json`: requests and expected responses, plus `startupCases`

## Verify (before the human check)
- Against `../SPEC.md`: every rule in 6.4 has its fixture; every invalid fixture names an error from 6.5.
- Against `../build/APPROVED-v0.6.sha256`: unchanged unless an amendment is recorded.
- Stale when: `SPEC.md` or the generator changes.

## Outputs
Only `fixtures/`. This folder never contains tests or code.

## Human check
The owner approves the amendment behind any fixture change. Pass = a new hash file next to the new contract version.

## Avoid
- Editing fixtures to make a failing test pass. Fix the code, or propose an amendment.
- Opening fixture files in an editor that adds a BOM or changes line endings (several fixtures are byte-exact).
